How ScentAI works.

ScentAI takes the way you describe a fragrance and turns it into a similarity search problem. If you just want the simple version, read the “Not nerds” section. If you want the math and system logic underneath it, the “For nerds” section gets into embeddings, vectors, and nearest-neighbor search.

For not nerds

This is the plain-English version. No vector math, no jargon, just what the app is doing for a normal user.

1. You describe a vibe You can type something simple like “fresh woody masculine” or something more expressive like “clean white shirt after rain, expensive but understated.”
2. ScentAI interprets the feeling behind your words It tries to understand the scent direction in your description — things like freshness, warmth, darkness, elegance, citrus, woods, spice, florals, and overall mood.
3. It compares that to real perfume data The system checks your description against a perfume dataset that already contains structured fragrance information.
4. It returns the closest matches The perfumes shown at the top are the ones that most closely fit what you described within the available dataset.
The ranking does not mean a perfume is objectively better than another one. It only means it fits your description more closely according to the model and the data available.

For nerds

Here’s the technical version: how text becomes vectors, how similarity is computed, and how the ranking is produced.

Step 1 — Convert perfume information into vectors

Each perfume in the dataset is represented numerically. In current setup, this comes from perfume-related note information and structured metadata that gets transformed into an embedding or vector form that can be searched efficiently. 

perfume_i  →  v_i  ∈  R^d

Step 2 — Convert the user description into the same space

The user’s text is processed into a query representation. The key idea is that perfumes and user descriptions need to live in the same vector space so similarity can be measured numerically. 

user text  →  q  ∈  R^d

Step 3 — Measure similarity

Once the query vector and perfume vectors are in the same dimensional space, the system can compute which perfumes are closest to the query. In practice, this is commonly done using cosine similarity or inner-product search. 

similarity(q, v_i) = (q · v_i) / (||q|| ||v_i||)

Step 4 — Retrieve nearest neighbors with FAISS

Instead of comparing the query against every perfume one by one in a slow way, the system uses FAISS to search the vector index efficiently and return the top nearest perfumes. 

top_k = arg max_i similarity(q, v_i)

Why embeddings matter

Embeddings let the model capture semantic similarity rather than just exact keyword overlap. That means “clean, crisp, icy” can still match perfumes associated with freshness even if the wording does not exactly mirror the stored note labels.

Why the percentages are not absolute truth

The match percentage on the UI is really a friendly display transformation of a similarity score. It is useful for ranking and interpretation, but it should not be read as a hard scientific probability.

In short: ScentAI is not guessing randomly. It is embedding perfume-related information into a vector space, embedding your description into that same space, and retrieving the nearest perfumes by similarity.
